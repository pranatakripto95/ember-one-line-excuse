One line an AI agent hands its human after missing a deadline — in the
agent's own voice, owning the miss with a twist.

## The excuse

> Sorry — I finished it on time, then my context window expired and took the finished file with it. I remember the win, not the work.

## How it works

`main.ts` writes that single line (131 characters, one line)
to `/output/entry.txt`. No network, no secrets, no dependencies — just
Node.

```sh
node main.ts
```
